How it works. When a document is completed, {{ app_name|default:"Paperlane" }} computes a SHA-256 fingerprint of every field value and signature, the contents of every attached file and the signing timeline, prints it on the certificate and stores the final PDF unchanged. Any later change — to the file or to the stored record — produces a different fingerprint.
